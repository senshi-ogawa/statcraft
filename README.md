# Stat Craft

食事・運動・睡眠・サプリの報告から、体の7つの状態（シャキッと度、集中力、気分の安定、体の軽さ、勢い・うるおい、脂肪の燃えやすさ、回復・体づくり）と数時間先の予測を見える化する、個人用のスマホ向け Web アプリです。

## 仕組み
追加費用を発生させないため、AI の計算は、利用者がすでに契約している AI（ChatGPT、Claude、Gemini など）で行います。アプリが作った依頼文をコピーして AI に貼り、AI の答えを貼り戻すと、結果が表示されます。サーバーや API キーは使いません。

## データ
履歴は、使っているブラウザの中（localStorage）にだけ保存されます。設定画面から CSV でコピーして保管でき、貼り付けて取り込めます。

## ファイル
- `index.html`：アプリ本体（1ファイル）
- `manifest.webmanifest`、`sw.js`、`icons/`：ホーム画面への追加と、通信がなくても開く仕組み

結果は一般的な目安による推定で、医療上の助言ではありません。
